# Запуск демо анимации графа

Демо показывает обработку заказа на компактном графе из 8 сущностей и 9 связей. Возможности показываются последовательно, с пояснениями и паузами, а не одновременно на всех связях.

[English guide](README.en.md)

## Требования

- StructView запущен на компьютере, где открыт граф.
- Python 3.11 или новее.
- Для обычного локального запуска дополнительные Python-пакеты не нужны.

## Запуск

1. Откройте в StructView файл [`fixtures/GraphAnimationDemo.toml`](fixtures/GraphAnimationDemo.toml).
2. Переключитесь на представление графа и дождитесь завершения построения и маршрутизации.
3. Откройте **Settings → Graph animation API**, включите API и скопируйте показанные адрес и токен.
4. В PowerShell перейдите в корень репозитория и запустите контроллер, указав адрес API:

   ```powershell
   python tests\demo_graph_animation.py --api http://127.0.0.1:8088
   ```

   Замените `http://127.0.0.1:8088` адресом из окна настроек StructView. Введите токен в скрытый запрос консоли.
5. Откройте адрес локальной панели, напечатанный контроллером, обычно `http://127.0.0.1:8765`.

По умолчанию контроллер **ничего не запускает автоматически**. В панели нажмите **Both**, **Scheduled** или **Realtime**. Текущая глава и объяснение отображаются в панели и консоли. Для остановки нажмите **Stop / clear** или прервите контроллер сочетанием `Ctrl+C`.

Для первого знакомства рекомендуется пошаговый режим:

```powershell
python tests\demo_graph_animation.py --api http://127.0.0.1:8088 --step-by-step
```

Запустите выбранный режим кнопкой панели. На каждой контрольной точке демо ждёт нажатия **Next chapter / Далее**. Держите StructView рядом с панелью, чтобы спокойно рассмотреть результат.

Контрольная точка не замораживает сценарный проигрыватель: временная подсветка
и движущиеся сценарные маркеры завершаются до ожидания. Камера сохраняет
положение, а realtime-эффекты и задания остаются для осмотра.

## Что показывает демо

| Главы | Возможности |
| --- | --- |
| 1–3 | Вписывание графа, фокус на сущности, изменение масштаба |
| 4–5 | Статическая и пульсирующая подсветка с выбором цвета |
| 6–9 | Движение по связи, сегмент 25–75%, обратное направление, очистка сценария |
| 10–12 | Ожидающее задание, живой прогресс, запоздалое обновление, два задания на одном маршруте и узле |
| 13–16 | Смена этапа и места выполнения, ошибка, повтор, остановка только одного задания |
| 17–19 | Совместимость со старым realtime API, независимая очистка слоёв, просмотр состояния |

В приложении раскройте **Задания графа**: список показывает название, ID, статус, этап, целевой процент и место выполнения. Кнопки сущностей и маршрутов переводят фокус к соответствующему узлу. На графе видны короткие подписи заданий; наведение раскрывает полные сведения. Маркеры показывают сглаженный текущий процент. Одновременно демонстрируется не более двух заданий.

## Варианты запуска

Быстро выполнить оба режима и завершить работу без веб-панели:

```powershell
python tests\demo_graph_animation.py --api http://127.0.0.1:8088 --once
```

Запустить только realtime-анимацию на ускоренной скорости:

```powershell
python tests\demo_graph_animation.py --api http://127.0.0.1:8088 --mode realtime --speed 2
```

Чтобы сразу запустить выбранный режим с автоматическими паузами, добавьте `--autoplay`. Полный обзор на скорости `1` занимает примерно полторы минуты. После realtime-обзора завершённое задание остаётся для изучения; удалите его кнопкой **Stop / clear**. В режиме `--once` панель не создаётся, поэтому автоматическое завершение не очищает итоговое задание.

Доступные параметры:

| Параметр | Назначение |
| --- | --- |
| `--api URL` | Обязательный HTTP/HTTPS адрес из настроек API StructView |
| `--mode both\|scenario\|realtime` | Режим демо; по умолчанию `both` |
| `--speed 0.1..10` | Скорость анимации; по умолчанию `1` |
| `--port PORT` | Порт локальной панели; `0` выберет свободный порт |
| `--once` | Не запускать панель; выполнить демо и выйти |
| `--autoplay` | Сразу начать выбранный режим, не ожидая кнопки запуска |
| `--step-by-step` | Ждать кнопки «Далее» на контрольных точках; несовместим с `--once` |
| `--graph PATH` | TOML-файл графа, который должен быть открыт в StructView |
| `--ca PATH` | PEM-сертификат центра сертификации для внутреннего HTTPS |

По умолчанию используется компактный граф. Для проверки большого графа откройте `fixtures\Graph.toml` в StructView и передайте его контроллеру:

```powershell
python tests\demo_graph_animation.py --api http://127.0.0.1:8088 --graph tests\fixtures\Graph.toml
```

## Токен и безопасность

Контроллер запрашивает API-токен скрытым вводом. Вместо этого токен можно передать через переменную окружения PowerShell:

```powershell
$env:STRUCTVIEW_API_TOKEN = Read-Host "StructView API token"
python tests\demo_graph_animation.py --api http://127.0.0.1:8088
Remove-Item Env:\STRUCTVIEW_API_TOKEN
```

Не добавляйте токен в исходный код и не передавайте его аргументом командной строки. Локальная панель слушает loopback-интерфейс и не предназначена для публикации в сеть. Для HTTPS укажите HTTPS-адрес API; при использовании внутреннего CA добавьте `--ca C:\path\to\ca.pem`. Проверка сертификата при этом остаётся включённой.

Контроллер проверяет, что открытый в StructView граф соответствует выбранному TOML-файлу. Если узлы или связи отличаются, откройте корректный граф либо укажите правильный `--graph`.

## Управление заданиями и API

Используйте в панели **Create / update job**, **Stop this job**, **Clear jobs only**, задавая ID, подпись, этап, статус, процент, сущность и маршрут. Разные ID создают независимые задания. Во время обзора ручные изменения запрещены; чтение состояния доступно всегда.

Новые endpoints:

- `GET /v1/capabilities` — возможности и ограничения сервера.
- `GET /v1/jobs` — список заданий, их этапов, целей и прогресса.
- `POST /v1/jobs` — атомарный пакет `upsert`, `remove` или `clear`.

`upsert` передаёт полное состояние задания. В одном этапе прогресс не уменьшается; при смене этапа, связи или направления начинается новый прогресс. Для повтора задавайте новое имя этапа. Старые `/v1/animation` и `/v1/realtime` продолжают работать независимо от заданий. Подробный контракт и JSON-примеры: [основной README](../README.md#jobs-independent-executions).

Если контроллер сообщает, что API не поддерживает задания, обновите и перезапустите StructView. Демо проверяет поддержку через `/v1/capabilities`.
